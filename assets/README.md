# assets

Déposez le logo officiel du festival ici, sous le nom exact :

    logo.png

Le site le détecte automatiquement au chargement et remplace le sceau SVG
intégré (en-tête + hero). Tant que le fichier est absent, c'est la version
vectorielle qui s'affiche.

Format conseillé : PNG carré, fond transparent ou bleu marine, 1000 × 1000 px.
