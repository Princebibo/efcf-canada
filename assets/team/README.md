Les photos sont recadrées en cercle par le site (`object-fit: cover`, centrées
sur le haut du portrait) : n'importe quel format fonctionne, mais une image
carrée d'environ 800 × 800 px donne le meilleur résultat.

Tant qu'un fichier est absent, la personne s'affiche avec un médaillon
d'initiales sur fond bleu marine — rien ne casse.
